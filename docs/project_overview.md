# Project overview

ATLAS-Evo is a public-data benchmark framework for condition-aware cis-regulatory sequence modeling. It combines interpretable sequence grammar, theory-inspired proxy modules, nonlinear prediction heads, and explicit evidence-tier assignment.

The main design principle is evidence separation. Results from independent context tests, related/proxy branches, prediction-derived branches, and capacity-oriented analyses are retained but not collapsed into a single undifferentiated ranking.
