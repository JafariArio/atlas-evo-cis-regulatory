# Public data sources

Raw public data are not bundled in this repository. Use the original public resources:

- Random Promoter DREAM: Zenodo record `10.5281/zenodo.10633252`.
- PARM promoter MPRA resource: NCBI GEO accession `GSE301246`.
- Exploratory regulatory-context resource: NCBI GEO accession `GSE221384`.

Processed metadata and result summaries are provided in `data/processed_metadata/` and `results/tables/`.
